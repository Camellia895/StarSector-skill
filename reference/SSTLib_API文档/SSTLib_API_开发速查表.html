🔮 反射开发速查

⚠️ 适用场景：访问未公开的内部类和方法（如 UI 内部面板、AppDriver、CampaignState 等）。 能用公开 API 实现的不要用反射。参考 LunaLib ReflectionUtils.kt。
🔒 安全限制：游戏脚本类加载器在类加载时拦截 java.lang.reflect.Method / Field，任何代码中声明这些类型（变量、参数、返回值）都会抛出 SecurityException，即使从未调用。
❌ IMPL_LOOKUP 方案已弃用：获取 IMPL_LOOKUP 字段本身需要反射 Field 类型，同样被拦截。
✅ 正确方案：Class.forName + MethodHandles.lookup()，完全不引用反射类型。

核心原则（ChineseInputFix 实测可行）

原则说明
Class.forName 加载反射类用 Class.forName("java.lang.reflect.Method", false, Class.class.getClassLoader()) 获取 Class 对象，不直接 import
MethodHandles.lookup() 创建句柄用 MethodHandles.lookup().findVirtual(methodClass, "invoke", ...) 创建 MethodHandle
所有反射对象当 Object 处理变量、参数、返回值一律用 Object，不用 Method/Field
缓存结果用 HashMap 缓存反射查找结果，键为 (类, 名称, 参数数)
public + declared同时搜索 getMethods()/getDeclaredMethods()，强制转型为 Object[]
预定义方法名列表UI 遍历时不要枚举 getMethods()，用预定义的 getter 名称列表逐个 invoke 尝试

🔑 绕过安全限制关键代码（实测可行）

// 1. 用 Class.forName 获取反射类的 Class 对象（不直接 import）
ClassLoader jdkLoader = Class.class.getClassLoader();
Class<?> methodClass = Class.forName("java.lang.reflect.Method", false, jdkLoader);
Class<?> fieldClass = Class.forName("java.lang.reflect.Field", false, jdkLoader);

// 2. 用 MethodHandles.lookup().findVirtual() 创建 MethodHandle
MethodHandle invokeHandle = MethodHandles.lookup().findVirtual(methodClass, "invoke",
        MethodType.methodType(Object.class, Object.class, Object[].class));
MethodHandle getNameHandle = MethodHandles.lookup().findVirtual(methodClass, "getName",
        MethodType.methodType(String.class));

// 3. 查找方法：返回 Object，不是 Method
Object[] methods = (Object[]) clazz.getMethods();  // 强制转型，不声明 Method[]
for (Object m : methods) {
    String name = (String) getNameHandle.invoke(m);  // 通过 MethodHandle 调用
    if (name.equals("getCore")) {
        Object result = invokeHandle.invoke(m, instance, args);
    }
}

❌ 常见错误写法（会触发 SecurityException）

// ❌ 直接 import 反射类
import java.lang.reflect.Method;  // 类加载即抛异常

// ❌ 声明 Method/Field 类型变量
Method m = clazz.getMethod("getCore");  // 触发异常
Method[] methods = clazz.getMethods();  // 触发异常

// ❌ 使用 IMPL_LOOKUP（获取字段本身需要反射 Field）
Field f = MethodHandles.Lookup.class.getDeclaredField("IMPL_LOOKUP");  // 触发异常

典型用法（Java 版 ReflectionUtils）

// 1. 调用未公开方法
Object core = ReflectionUtils.invoke(state, "getCore");

// 2. UI 遍历：预定义 getter 名称列表（不要枚举 getMethods()）
String[] entryMethods = {"getCore", "getCurrentDialog", "getCurrentPanel"};
for (String name : entryMethods) {
    Object result = ReflectionUtils.invoke(campaignUI, name);
    if (result != null) { /* 处理 */ }
}

// 3. 读取/修改私有字段
Object value = ReflectionUtils.get(instance, "fieldName");

调度器模式（主菜单注册）

private ScheduledExecutorService scheduler;

private void startScheduler() {
    if (scheduler != null) {
        scheduler.shutdownNow();
    }
    scheduler = Executors.newSingleThreadScheduledExecutor();
    scheduler.scheduleAtFixedRate(() -> {
        try {
            GameState s = Global.getCurrentState();
            if (s == GameState.TITLE ||
                s == GameState.CAMPAIGN) {
                registerListeners();
                scheduler.shutdown();
            }
        } catch (Exception e) {
            scheduler.shutdown();
        }
    }, 0, 100, TimeUnit.MILLISECONDS);
}

✅ 最佳实践速查

🏗️ 架构设计
  • 继承 Base* 基类，不要直接实现接口
  • 监听器/脚本用 transient，onGameLoad 重注册
  • 能用公开 API 就不要用反射
  • 反射结果务必缓存
⚡ 性能优化
  • 每帧脚本中避免频繁反射
  • 集合遍历时不要修改集合
  • 用 IntervalUtil 控制执行频率
  • 缓存查询结果（同帧内多次查询）
🔒 兼容性
  • 反射调用加 try-catch 容错
  • 数据类实现 Serializable
  • configureXStream 注册自定义类别名
  • 避免修改其他 mod 的数据
🐛 调试技巧
  • 开发模式 F8 热重载
  • Global.getLogger()打日志
  • 用 isDevMode() 加调试代码
  • DevModeVenting等调试技能
📚 延伸阅读： 详细 API 说明请参阅 SSTLib API 指南， 交互式浏览请使用 SSTLib API 层级树。
